#### 2.2.4 底部操作栏

**① 麦克风按钮（主交互）**

- 点击开始录音 → 按钮变为红色脉冲动画 + 声波扩散效果
- 自动检测静音结束识别，识别结果文字显示到对话区

**② 快捷指令（展开菜单）**
- 点击展开 3 个预设文字标签：
  - "今天接了几单？"
  - "现在什么状态？"
  - "你好"
- 点击标签 → 自动发送到对话，不经过麦克风录音

**③ 文字输入（展开输入框）**
- 点击展开文本输入框 + 发送按钮
- 用于不方便说话的场景

## 三、交互状态机

### 3.1 四状态定义

```
                    ┌───────────────────┐
                    │                   │
                    ▼                   │
  ┌───────┐   点击话筒   ┌──────────┐   │
  │       │ ──────────→  │          │   │
  │ Idle  │              │Listening │   │
  │       │ ←──────────  │          │   │
  └───────┘   超时/取消   └──────────┘   │
      ↑                          │      │
      │                     ASR返回结果  │
      │                          ▼      │
      │                    ┌──────────┐  │
      │                    │          │  │
      │               ┌───│ Thinking │  │
      │               │   │          │  │
      │               │   └──────────┘  │
      │               │        │        │
      │               │   匹配到回复     │
      │               │        ▼        │
      │               │   ┌──────────┐  │
      │   点击话筒    │   │          │  │
      │   (打断说话)  └── │ Speaking │  │
      │                    │          │──┘
      │                    └──────────┘
      │                         │
      └─────────────────────────┘ TTS 播放完毕
```

| 状态 | 说明 |
|------|------|
| Idle | 空闲等待，数字人静态浮动，底部按钮可点击 |
| Listening | 录音中，数字人微微前倾，话筒脉冲动画，面罩蓝光闪烁 |
| Thinking | 处理中，数字人头部微歪，光效流动，对话区显示"..." |
| Speaking | 回复中，数字人轻微晃动，TTS 播放语音，文字打字机效果 |

### 3.2 转换规则

| 编号 | 从 | 到 | 触发条件 |
|------|-----|-----|---------|
| T1 | Idle | Listening | 用户点击麦克风按钮 |
| T2 | Idle | Thinking | 用户点击快捷指令 |
| T3 | Idle | Thinking | 用户发送文字消息 |
| T4 | Listening | Thinking | ASR 返回识别结果 |
| T5 | Listening | Idle | 用户再次点击麦克风取消 |
| T6 | Listening | Idle | 静音超时（10 秒无有效语音） |
| T7 | Listening | Idle | ASR 识别出错 |
| T8 | Thinking | Speaking | 匹配到回复内容 |
| T9 | Thinking | Idle | 无匹配 / 超时（3 秒） |
| T10 | Thinking | Listening | 用户点击麦克风打断 |
| T11 | Speaking | Idle | TTS 播放完毕 |
| T12 | Speaking | Listening | 用户点击麦克风打断 |

### 3.3 冲突处理

| 场景 | 规则 |
|------|------|
| 语音播放中点击话筒 | 允许打断，立即停止 TTS 进入 Listening |
| 思考中点击话筒 | 允许打断，取消匹配进入 Listening |
| 录音中点击快捷指令 | 忽略，录音优先 |
| 连续快速点击话筒 | 间隔 < 500ms 的点击忽略，防止状态震荡 |
| 关闭面板时有进行中的操作 | 强制终止，停止所有 ASR/TTS/匹配 |
| 5 秒内收到相同文本 | 去重，不重复处理 |

### 3.4 异常处理

| 异常 | 处理方式 |
|------|---------|
| 浏览器不支持 ASR | 隐藏麦克风按钮，仅保留文字输入和快捷指令 |
| 麦克风权限被拒绝 | 提示"请允许麦克风权限"，降级为纯文字模式 |
| TTS 播放失败 | 仅显示文字（打字机效果继续），不播放语音 |

## 七、对话内容设计

### 7.1 回复引擎规则

数字人的回复分三层匹配：

```
用户输入
    │
    ├─ 关键词匹配 → 匹配到预设的关键词 → 返回对应回复
    │（如 "你好" → "你好呀！我是花小猪助手～"）
    │
    ├─ 状态查询 → 匹配到查询类意图 → 读取 Store 数据 + 格式化回复
    │（如 "今天接了几单" → "你今天接了 X 单，收入 Y 元"）
    │
    └─ 兜底回复 → 以上都不匹配 → 统一回复
       （"这个问题我还不太明白，不过我会继续学习的！"）
```

### 7.2 预设对话列表（Phase 1）

| 用户说 | 数字人回复 |
|--------|-----------|
| 你好 / 嗨 / 在吗 | 你好呀！我是花小猪助手，有什么可以帮你的吗？ |
| 今天接了几单 / 今天怎么样 | 你今天接了 {orders} 单，总收入 {earnings} 元，{statusText} |
| 现在什么状态 / 在干嘛 | 你目前 {statusText}，{listeningText} |
| 你叫什么名字 / 你是谁 | 我是花小猪助手，你的专属 AI 驾驶伙伴！ |
| 你好可爱 | 嘻嘻，谢谢！穿上这身机甲，我可是要保护你安全驾驶的！ |
| 再见 / 拜拜 / 退下 | 好的，有事随时叫我，我在右下角等你～ |
| 谢谢 | 不客气！有需要随时找我～ |
| 无聊 / 聊聊天 | 那我给你讲个笑话：为什么程序员总是分不清万圣节和圣诞节？...因为 Oct 31 = Dec 25！ |
| （无匹配） | 这个问题我还不太明白，不过我会继续学习的！你可以问我接单情况或者跟我聊聊天～ |

### 7.3 上下文数据

数字人读取 Store 中的司机状态来回答查询类问题：

```typescript
interface SceneContext {
  driverStatus: "offline" | "idle" | "busy";
  isListening: boolean;
  todayOrders: number;
  todayEarnings: number;
}
```

### 7.4 多轮对话

- 同一会话中，消息列表保留最近 10 轮对话
- 关闭面板时，当次对话最后 20 条保存到 localStorage（保留 7 天）
- 再次打开面板可恢复历史对话

## 十、性能兜底

| 级别 | 条件 | 动画策略 |
|------|------|---------|
| 全量 | 默认 | 浮动 + 光效呼吸 + 脉冲 + 声波 |

Web Speech API 兼容：运行时检测 `window.SpeechRecognition || window.webkitSpeechRecognition`，不存在时隐藏麦克风按钮。

| 层级 | 方案 |

## 十二、设计原则

1. **高度还原原图**：所有形象必须直接从原图裁剪或缩放，不重绘、不修改
2. **品牌统一**：粉色主调 + 浅蓝霓虹光效贯穿所有交互元素
3. **Q 版萌感优先**：所有动画和交互保持轻松、友好的调性
4. **语音优先**：语音为主、文字为辅，降低操作门槛
5. **渐进增强**：Phase 1 纯前端，后续可接 LLM 扩展对话能力
